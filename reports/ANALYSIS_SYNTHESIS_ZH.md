# 实验与结果分析综合（2026-11-08；基于已完成的 Phase 1、Meta-World Phase 2、A3/A4、P2；数字出处见各报告）

## 一、可以推得的（证据较强）
1. 在两层任务上，4（Tier-0）/2（Meta-World）个 LLM 臂都显著优于随机编辑（Holm p≈0.006–0.024）。
2. 编辑者**没有**对 16 个开发 episode 过拟合：最后一轮开发集成功率与隐藏 ID 成功率之差均值 |gap|≤0.03（Tier-0：Opus·high +0.004、Opus·med −0.006、Sonnet·high −0.015、Sonnet·med +0.020；Meta-World：−0.027、−0.019）。隐藏增益是真实的，不是开发反馈的伪影。
3. 行为画像（按运行统计，R=4）：几乎总是第 1 轮就编辑（首次编辑轮次均值 1.0–1.2）；之后约一半的轮次提交“不改”。Meta-World 上 **Sonnet·med 有 41% 的运行整场一次都不编辑，Opus 为 0%**（Tier-0：Sonnet·med 19%、Sonnet·high 6%、Opus 0%）。→ Sonnet 在官方层的弱点主要是**弃权**，不是改坏（改坏的 Regression 约 0.07）。
4. 运行间方差结构（Tier-0，8 个检查点各 2 次，仅作线索）：Sonnet·med 组内相关 ICC≈0.79（逐检查点很稳定，稳定地小改或不改），Opus·med ICC≈0.27（运行间波动大，来自整体重写的高方差）。
5. 官方层比机制层保守：Meta-World 上对特权闭式重拟合显著更差（−0.22 到 −0.35，Holm 0.024），Opus 与 gain_greedy 持平。
6. 读权重无可测平均收益（WRI +0.006，[−0.088, +0.099]，n=16 对）；盲读时更倾向整体重写。

## 二、可作假说（需要新数据检验，不是结论）
- “给了权重反而更保守”：看到权重的模型倾向小改动，盲读时被迫写整套控制器，在需要重写的任务（c02-S2）上盲读反而更好。检验：在同一检查点上做“强制整体重写”提示。
- “Opus 的高方差来自重写策略”：检验：按编辑机制分层的运行间方差；需要更多重复。
- “探针少用是因为模型不信任/不需要探针”：检验：探针赛道主批的探针使用读数。

## 三、不能推得的
- 不能说“LLM 读懂了权重”（WRI≈0，增益可由整体缩放/重写解释）。
- 不能说“LLM 修复优于或等于闭式解”（Tier-0 不显著不等于等价；官方层显著更差）。
- 不能把 Tier-0 与 Meta-World 合并成一个总数；不能说 high 档更好或更差（Sonnet 略升、Opus 略降，CI 含 0 或勉强）。
- 不能把 n=6–17 个聚类的点估计当稳定排名；单次运行不可靠（σ_run 0.08–0.13）。
- 不能把 Claude 结果推到 GPT。

## 四、不耗模型额度、现在就能做的分析
机制分层的增益与方差；编辑位置/规模与增益；按失败类型的修复率；OOD 曲线（Meta-World）；对照臂梯度的 bootstrap 排名稳定性；功效与最小可检差更新；Meta-World 弃权运行的提示与首轮报告对比（是否因为初始报告成功率高而选择不改）。
## 五、需要新运行才能回答
规模阶梯（读权重依赖度随宽度变化）；探针赛道（大网络）；“强制重写”与“弃权诱因”诊断；更多重复以估计模型间差异的置信区间；GPT 侧对照（用户安排）。
