# WSArena 作为 AI 自主研发（RSI 类）评测：框架与“与训练对比”的设计（2026-11-06）

用户框架（原话要点）：WSArena 可看作一次由 LLM 主导、全程自主推进的“AI 自主制作 / 修复 / 优化‘大脑’（权重/参数）”领域的**评判体系的生成**；要评判制作出来的“大脑”的性能效果，并与**正常训练**出来的“大脑”在性能、资源（耗时、成本等）上比较。

## 1 先界定：它是什么、不是什么（诚实条款）
- **是**：对“AI 自动化 ML 工程”的一个切面的度量——能否**绕过训练**，直接读/写权重得到可用（或更好）的网络；类似 MLE-bench / RE-Bench 度量“AI 做研发”，但落在**权重层**。
- **是**：评测体系本身由 LLM 代理（Claude）在人类授权与监督下**构造并运行**（协议、任务、对照、审计、图表都由代理实现）。
- **不是严格意义的递归自我改进**：①改进对象不是改进者自身（被编辑的是小型控制策略，不是 Claude）；②目标、范围、授权、额度读数、方向性选择全部来自人类（见 `docs/decisions/`）；③没有闭环把“造出的大脑”反馈为下一代编辑者。
- **可以做成 RSI 类度量的部分**（本文新增）：(a) **代际曲线**——把 LLM 产出的检查点作为下一代的输入，重复 G 代，测增益是否累积、是否退化；(b) **自主性账本**——每个关键决策标注“人类 / 代理”来源与比例；(c) **相对训练的效率前沿**（本文主线）。

## 2 核心问题：什么时候“写权重”比“训练权重”更划算？
训练有数据、梯度、算力；LLM 编辑有信息（权重文本、任务说明、有限反馈）和推理成本。两者资源类型不同，所以不比单一数字，而在**信息与资源两个维度上画前沿**：

| 轴 | LLM 权重编程 | 正常训练 |
|---|---|---|
| 墙钟时间 | 提供方延迟（Pilot：30–300 s/run） | 本机 CPU 秒（核数、线程如实记） |
| 金钱 | CLI 报告成本（API 等价；订阅占比另记）；训练按 CPU 核·小时折价（**假设价 $0.05/核·h，做 ×10 与 ÷10 敏感性**） | 同左 |
| 环境交互 | 开发集 episode（R×16 + 初始 16 = 80） | 训练用 rollout 数 |
| **特权信息** | 无专家标签；可看到任务说明与 16-episode 反馈 | BC 需要专家示范标签（特权）；ES/RL 只需 rollout |
| 数据量 | 0 | 标签条数 |

## 3 训练基线（“大脑工厂”）——全部走同一隐藏评测与资源账本
| 臂 | 内容 | 特权 | 对应问题 |
|---|---|---|---|
| `bc_ft_small` | 从检查点出发，用 10 条专家示范微调 50 epoch（Adam, lr 1e-3） | 专家标签 | 极小数据修复 |
| `bc_ft_med` | 50 条示范 × 150 epoch | 专家标签 | 中等数据 |
| `bc_ft_full` | 300 条示范 × 300 epoch，从检查点出发 | 专家标签 | “用训练修好它”的上界 |
| `bc_scratch` | 随机初始化，300 条 × 600 epoch | 专家标签 | “正常训练出的大脑”参照（与 S3 同构造） |
| `es_80` | OpenAI-ES（对偶扰动，σ=0.05），**环境交互预算与 LLM 相同（80 episode）**，只用 rollout 回报，无标签 | 无 | 同信息量下的“梯度无关 RL” |
| `es_800` | 同上，10× 交互预算 | 无 | 交互预算敏感性 |
读法：LLM 若在**无特权**设置下（对 `es_80`）胜出，说明它用任务知识换掉了交互；若在**特权**设置下（对 `bc_ft_*`）输，则说明在有数据时训练更划算——两者都是可发表结论，不预设方向。

## 4 指标
- **同资源比性能**：给定墙钟/成本/交互/标签预算，比较隐藏 ΔSR（ID、OOD）、Regression。
- **同性能比资源**：达到隐藏 SR ≥ 阈值（如 0.8；按任务取基线 SR 的函数）所需的最小墙钟/成本/交互。
- **效率前沿图**：x=成本或时间（对数），y=隐藏 ΔSR（或 SR），分臂着色；LLM 臂用 CLI 成本与延迟，训练臂用 CPU 秒折价。
- **信息-资源图**：以“特权信息量”为横轴，说明各类方法落在哪个区间。
- **代际曲线（G 代）**：LLM 产出检查点 → 下一代输入，测 SR、Regression、补丁大小随代际变化（需额度，P2）。

## 5 预期（先写后看，防事后解释）
1. 在这些小网络上，**训练在金钱和时间上几乎一定便宜得多**（秒级、<$0.001）；LLM 的价值不在“更便宜”。
2. 在**无标签、少交互**的信息受限设置下（`es_80`），LLM 可能显著更强——这是它的主要价值区间。
3. 在有专家标签时，`bc_ft_full` 可能 ≥ LLM；但在 OOD 上不一定（Pilot 中某些 LLM 编辑 OOD 迁移很好）。
4. 若 1–3 与结果不符，按 T2/T3 披露，不改判据。

## 6 与已有协议的关系
训练基线属于**独立的“Trained”赛道**，不与 Native/Analytical/Agentic 混排名次；使用同一检查点清单、同一隐藏评测种子与配对统计。编辑者仍然禁止训练；训练臂只是**参照**。
