# P6 探针赛道（Probe track）设计（2026-11-08；设计稿，实现前冻结预注册）

**目的**：Native 赛道把全部权重文本塞进提示词，上限约 2 万参数（宽度 128）。真实策略网络要大得多；Playground 的做法是给 agent 沙箱和只读探针。探针赛道回答：**当网络大到放不进提示词时，LLM 仅靠受限的只读探针能否完成编辑？** 它与 Native **分榜、不混排**（赛道名不同、能力不同）。

## 1 核心设计：文本中转探针，不开 CLI 工具
`claude -p` 仍然 `--tools ""`（审计不变：init 里工具/MCP/技能必须为空）。探针由**协议层**提供：模型在回复里写 ```probe 代码块，harness 在下一回合把结果作为用户消息返回（回合仍是无状态、全部历史重渲染）。好处：①配额与读取量由服务端强制；②每次探针记录在 run 里，可重放；③不引入沙箱/任意代码，**探针不能运行环境、不能训练、不能搜索**。

**探针指令（全部只读，作用在“当前权重”上）**
| 指令 | 返回 | 单次上限 |
|---|---|---|
| `shape` | 各张量形状与参数数（初始消息已给，探针重复不计费） | — |
| `slice T[a:b, c:d]` | 该切片的数值（5 位有效数字） | 400 个数 |
| `stats T[axis=0|1]` | 沿轴的均值、方差、最大/最小绝对值、L2 范数（每行/列） | 返回 ≤200 行 |
| `topk T k=…` | 绝对值最大的 k 个元素的下标与值 | k≤50 |
| `forward obs=[…]` | 在给定观测上的动作输出，及可选 `layers=1,2` 返回各层隐藏激活的摘要（前 16 个单元） | 观测 ≤8 条 |
| `grad`/`optimise`/`rollout` | **不存在**（写了即无效，计数并回传） | — |
`forward` 只调用网络本身，不接触环境；观测由模型自己构造（它能拿到环境描述）。

## 2 预算（服务端强制，写进预注册）
每轮最多 **P=3 个探针子回合**，每个子回合最多 4 条探针指令，**全程总返回量上限 8,000 个数**；超额指令被拒绝并回传“预算用尽”；用尽后必须在本轮给出 ```edits```。轮数与反馈同 Native（R=4，每轮 16 dev episode）。额度成本约为 Native 的 (1+P) 倍，因此先做小样本。

## 3 任务与检查点
c02-avoid 的宽度阶梯继续往上：@w256（约 7 万参数）、@w512（约 27 万参数）；BC 检查点用现有构造器（`make_tasks.py`）；Meta-World push 作第二任务。同一检查点同一 episode（`seed_for` 已保证）。**初始提示不含权重值**，只给形状、环境说明、初始报告与探针语法。

## 4 对照与读数
- **同权限对照（脚本）**：`blind`（Native 盲读，无探针；已有协议）、`compiled_pd`（给控制知识的上界）、`gain_greedy`、`tensor_gain_greedy`、`analytic_ridge`（特权）、`oracle_restore`。
- **关键读数**：ΔSR（隐藏 ID/OOD）；**探针使用量**（条数、返回数值量、哪类指令）；探针 vs 盲读的差 = “只读探针带来的增量”（探针版 WRI）；编辑机制分布；成本。预先写定判读：探针与盲读的聚类均值差的 CI 下界 >0 → “探针提供了可测收益”；含 0 → “未见收益”。
- 独立排名；不与 Native 混排；报告里同表并列只为对照。

## 5 审计与测试（实现时必须有）
探针解析的分类测试（合法/超限/非法指令）；结果只含当前权重的函数（不泄漏基线/隐藏信息）；`forward` 与 `mlp.forward` 一致；重放（保存的探针回合重放得到同样结果）；预算计数与拒绝；泄漏审计沿用 A6；提示逐字节一致性（除权重块外同 Native，另有 `check_prompt_parity` 的探针版）。

## 6 实现计划（CPU，不耗额度）
1. `wsarena/probe.py`：解析 + 执行 + 预算；2. `protocol.py`：`track="probe"`（子回合循环、预算、原始事件保存）——**改冻结文件，须升契约 v13 并做逐比特回归**（Native 路径不变）；3. `prompts.py`：探针版首条消息；4. 测试；5. 小样本可行性（w256，4 个运行）→ 预注册 §15 → 主批。
**范围声明**：探针赛道不要求 GPU 或集群（全部 numpy）；如后续要加 Kinetix 大网络（17 万参数），再单独请示。
